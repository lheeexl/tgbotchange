# Project Change Bot

Полноценный учебный прототип информационной системы управления проектными изменениями внутри Telegram.

## Возможности

- регистрация проектного изменения через FSM;
- автор, Telegram ID, username, ФИО и даты;
- приоритет, область проекта, влияние на сроки и стоимость;
- ответственный и его Telegram ID, если ID известен;
- статусы: `new`, `review`, `approved`, `rejected`, `in_progress`, `completed`, `cancelled`;
- неизменяемая история статусов в `change_history`;
- просмотр своих и всех изменений;
- карточка изменения;
- редактирование полей;
- поиск и фильтрация;
- статистика;
- уведомления автора, ответственного и администратора;
- CSV-экспорт изменений и истории;
- административный режим;
- тесты CRUD, истории, фильтрации, статистики и экспорта.

## Установка

Требуется Python 3.12+.

### 1. Создать виртуальное окружение

Windows:

```powershell
python -m venv .venv
.venv\Scripts\activate
```

Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Создать Telegram-бота

1. Откройте `@BotFather`.
2. Выполните `/newbot`.
3. Укажите имя и username.
4. Скопируйте Bot Token.

### 4. Создать `.env`

Скопируйте `.env.example` в `.env`:

```env
BOT_TOKEN=ваш_токен
ADMIN_ID=ваш_числовой_telegram_id
DATABASE_URL=sqlite+aiosqlite:///./project_changes.db
```

`ADMIN_ID` должен быть числовым Telegram ID администратора.

### 5. Запустить

```bash
python run.py
```

База SQLite создастся автоматически.

- `/export`
- `/admin_search_title слово`

## История статусов

При создании записи создаётся первоначальная строка:

```text
NULL -> new
```

При каждом последующем изменении статуса добавляется новая строка с:

- старым статусом;
- новым статусом;
- Telegram ID пользователя;
- именем пользователя;
- временем;
- комментарием.

Старые записи не изменяются.

## Поиск и фильтрация

В меню `🔎 Найти изменение` доступны:

- поиск по ID;
- поиск по названию;
- фильтр по статусу;
- фильтр по приоритету;
- фильтр по области;
- список активных изменений.

## Редактирование

Автор изменения и администратор могут редактировать поля карточки. Статус изменяется отдельным сценарием, поэтому изменение статуса всегда попадает в audit trail.

## Экспорт

Администратор:

```text
⚙️ Администрирование
    ↓
📤 Экспорт
```

или команда:

```text
/export
```

Получает два CSV:

- `changes.csv`
- `change_history.csv`

## Тесты

```bash
pytest -q
```

Тесты работают на временной SQLite БД и не требуют Telegram API.

## Безопасность

- Bot Token находится только в `.env`;
- `.env` включён в `.gitignore`;
- административные обработчики проверяют `ADMIN_ID`;
- токен не записывается в логи;
- SQL выполняется через SQLAlchemy ORM.

## Примечание об ответственном

Поле `responsible_person` является текстовым, как предусмотрено заданием. Если пользователь указывает Telegram ID в формате `123456789`, бот также сможет использовать его для уведомления. Если указан обычный текст вроде `Иванов И.И.`, бот не может надёжно определить Telegram-пользователя и уведомляет только автора и администратора.
